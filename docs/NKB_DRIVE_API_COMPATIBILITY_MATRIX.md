## 2. COMPATIBILITY GUARANTEES

1. **Database Schema Immunity:** None of the 42 existing tables in the `nkb_cloud_local_test` database will be dropped, altered, or renamed.
2. **Session Compatibility:** All tokens generated by the desktop client conform strictly to the existing `server/config/jwt.js` standard, guaranteeing seamless invalidation upon password reset or admin revocation (`session_version` integer check).
3. **Multi-Platform Interoperability:** A file uploaded or renamed from `N:\` in Windows File Explorer is immediately visible and accessible in the NKB Cloud Web Client, Mobile Client, and macOS/Linux agents without requiring manual synchronization or refresh.
